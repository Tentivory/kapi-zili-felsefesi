# KAPI ZILI FELSEFESI

## Projenin Amaci

Bu proje, insanligin en buyuk sorularindan birine cevap aramaktadir: **Kapı zili neden calar?**

Yillar suren arastirmalar, sayisiz deneme ve bir kac kahve sonrasi, kapı zilinin aslinda sadece bir ses degil, evrenin bize fısıldadığı bir mesaj oldugu anlasilmistir. Bu repository, o mesaji cozumlemek icin gelistirilmis bilimsel bir aractir.

## Nasil Calisir?

```bash
python3 kapi_zili.py
```

Program calistirildiginda:
1. Derin bir sessizlik baslar.
2. Zil sesi metafiziksel olarak analiz edilir.
3. Rastgele felsefi sorular uretilir.
4. Hayatinizin anlamı bir anligina netlesir (veya daha da karisir).

**Uyari:** Bu program gercekten calisir. Eger kapi ziliniz calarsa, once programi calistirin, sonra kapıyı acin. Sira onemli.

## Ozellikler

- Abartili yavaslik (dusunme sureci icin)
- Rastgele felsefe (her seferinde farkli kriz)
- Gercek Python kodu (hicbir sey uydurma degil)
- Sifir bagimlilik (sadece time ve random)
